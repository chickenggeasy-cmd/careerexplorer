# Career Explorer Pro (Updated 2026)

เว็บแอปพลิเคชันสำรวจอาชีพสำหรับนักเรียนไทย พัฒนาโดย องค์การค้าของ สกสค. เพื่อช่วยให้นักเรียนสามารถค้นหาเส้นทางอาชีพที่ใช่ สอดคล้องกับทักษะและความต้องการในอนาคต

---

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
career-explorer/
├── index.html          — หน้าหลัก + layout โครงสร้างแอปพลิเคชัน (SPA)
├── README.md           — เอกสารรายละเอียดโครงการอัปเดตล่าสุด
├── css/
│   ├── compare.css     — สไตล์ชีตสำหรับหน้าเปรียบเทียบอาชีพ
│   ├── floating-dock.css — สไตล์ชีตสำหรับเมนูด็อกลอยตัว
│   └── style.css       — ธีมสีหลัก, Layout, UI Components ทั้งหมด
└── js/
    ├── colorblind.js   — ระบบช่วยเหลือผู้มีภาวะตาบอดสี
    ├── compare-deco.js — สคริปต์จัดการเอฟเฟกต์หน้าเปรียบเทียบ
    ├── compare.js      — ระบบประมวลผลข้อมูลหน้าเปรียบเทียบ
    ├── data.js         — ฐานข้อมูลอาชีพ (14 สายงานหลัก, 400+ อาชีพ)
    ├── floating-dock.js — สคริปต์ควบคุมการแสดงผลด็อกลอยตัว
    ├── icons.js        — ระบบจัดการไอคอน SVG และ Emoji
    ├── loader.js       — ระบบจัดการหน้าจอ Loading
    ├── quiz.js         — ระบบแบบทดสอบประเมินสายงาน
    ├── render.js       — ฟังก์ชันควบคุมการแสดงผล UI
    ├── router.js       — ระบบจัดการเส้นทาง SPA Routing
    └── search.js       — ระบบสืบค้นและคัดกรองข้อมูลอาชีพ

```

## 📄 ระบบหน้าจอและฟังก์ชันหลัก

แอปพลิเคชันทำงานในรูปแบบ **Single Page Application (SPA)**:

| Page ID | เส้นทาง (Hash) | คำอธิบายฟังก์ชันการทำงาน |
| --- | --- | --- |
| `page-home` | `#page-home` | หน้าหลัก - Grid หมวดหมู่ 14 สายงาน และสถิติ |
| `page-cat` | `#page-cat` | หน้ารายการอาชีพในแต่ละสายงาน |
| `page-detail` | `#page-detail` | รายละเอียดเจาะลึกอาชีพ, รายได้ และทักษะ |
| `page-search` | `#page-search` | ระบบสืบค้นอาชีพผ่านคีย์เวิร์ด |
| `page-quiz` | `#page-quiz` | แบบทดสอบค้นหาความสนใจ (Career Matching) |
| `page-compare` | `#page-compare` | ตารางเปรียบเทียบอาชีพแบบ Side-by-Side |
| `page-about` | `#page-about` | ข้อมูลองค์กร สกสค. และเครดิตผู้พัฒนา |

## 💡 คำแนะนำสำหรับผู้รับช่วงต่อ (Developer Note)

* **การจัดการข้อมูล:** ปัจจุบันข้อมูลทั้งหมดถูกควบคุมผ่าน `js/data.js` ในรูปแบบ Static Object หากในอนาคตต้องการอัปเดตข้อมูลแบบ Real-time แนะนำให้พิจารณาเชื่อมต่อกับ **Firebase (Firestore)** หรือ **Supabase** เพื่อทำหน้าที่เป็น Backend-as-a-Service แทน
* **Accessibility:** ระบบมีการติดตั้ง `js/colorblind.js` ไว้เพื่อรองรับผู้ใช้งานที่มีข้อจำกัดด้านการมองเห็นสี โดยสามารถปรับแต่งค่าคอนฟิกได้ภายในไฟล์นี้

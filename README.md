# Career Explorer Pro
เว็บสำรวจอาชีพสำหรับนักเรียนไทย พัฒนาโดย องค์การค้าของ สกสค.

## โครงสร้างโปรเจกต์
- `index.html` — หน้าหลัก
- `css/style.css` — ธีมสีและ layout
- `js/data.js` — ข้อมูลอาชีพทั้งหมด
- `js/render.js` — แสดงผล UI
- `js/router.js` — จัดการการเปลี่ยนหน้า
- `js/search.js` — ระบบค้นหา

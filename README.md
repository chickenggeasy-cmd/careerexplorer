## 📄 ระบบหน้าจอทั้งหมด (Pages & SPA Routing)

แอปพลิเคชันทำงานในรูปแบบ **Single Page Application (SPA)** โดยควบคุมการเปลี่ยนหน้าจอผ่าน Hash Router ดังนี้:

| Page ID | เส้นทาง (Hash) | คำอธิบายฟังก์ชันการทำงาน |
| --- | --- | --- |
| `page-home` | `#page-home` | **หน้าหลัก** — ส่วน Hero Banner, Grid หมวดหมู่ 14 สายงาน และแถบสถิติ |
| `page-cat` | `#page-cat` | **หน้ารายการสายงาน** — แสดงผลอาชีพทั้งหมดภายใต้สายงานที่เลือก |
| `page-detail` | `#page-detail` | **หน้าเจาะลึกอาชีพ** — รายละเอียดรายได้, ทักษะ, ข้อดี/ข้อจำกัด และแนวโน้มเติบโต |
| `page-search` | `#page-search` | **หน้าผลลัพธ์การค้นหา** — แสดงรายชื่ออาชีพที่ตรงตามคีย์เวิร์ดหรือแท็กที่สืบค้น |
| `page-quiz` | `#page-quiz` | **หน้าแบบทดสอบ** — ทำแบบประเมินเพื่อวิเคราะห์สายงานที่เหมาะสม |
| `page-compare` | `#page-compare` | **หน้าเปรียบเทียบอาชีพ** — ตารางเปรียบเทียบข้อมูลอาชีพแบบเคียงข้าง (Side-by-Side) |
| `page-about` | `#page-about` | **หน้าเกี่ยวกับเรา** — ข้อมูลองค์กร สกสค. และประวัติทีมผู้พัฒนาระบบ |

## ⚙️ ฟังก์ชันสำคัญในระบบสคริปต์ (Core Functions)

### 1. ไฟล์ `js/render.js`

* **`renderCategories()`**: สร้าง Grid การ์ดแสดงผล 14 สายงานหลักบนหน้าแรก
* **`createJobCard(job, cat)`**: เทมเพลตสร้างการ์ดอาชีพเดี่ยวสำหรับนำไปจัดแสดงในหน้าสายงาน
* **`showCategory(catId)`**: โหลดข้อมูลแบนเนอร์และกลุ่มอาชีพของสายงานนั้นๆ มาแสดงผล
* **`showJob(jobId, catId)`**: เจาะลึกรายละเอียดอาชีพ (เงินเดือน 3 ระดับ, กราฟเปรียบเทียบ, วุฒิการศึกษา)

### 2. ไฟล์ `js/icons.js`

* **`applyIcons()`**: ทำหน้าที่สแกนเนื้อหาและแปลงสัญลักษณ์ Emoji ในตารางหรือการ์ด (เช่น `⚖️`) ให้เป็นไอคอนรูปภาพแบบ SVG เวกเตอร์ที่คมชัดโดยอัตโนมัติ
* **`SVG`**: Object เก็บโครงสร้าง Code XML ของไอคอนแต่ละตัว (เช่น `balance`, `brain_sm`)

### 3. ระบบ AI Chatbot (ฟีเจอร์เสริม)

* **`buildSystemPrompt()`**: ฟังก์ชัน Dynamic Prompting รวบรวมข้อมูลสถิติจริงจาก `DATA` (จำนวนอาชีพ/เงินเดือน) พร้อมผูกข้อมูลผู้พัฒนาเข้าสู่ระเบียบข้อบังคับ เพื่อส่งต่อให้ AI สวมบทบาทเป็น Advisor ควบคุมความถูกต้องภาษาไทยไม่เกิน 50 คำ

## 📝 รูปแบบโครงสร้างข้อมูลอาชีพ (`js/data.js`)

```js
const DATA = {
  categories: [
    {
      id: "medical",        // รหัสอ้างอิงหมวดสายงาน
      nameT: "สายการแพทย์และสุขภาพ", 
      nameE: "Medical",     
      icon: "...",          
      color: "...",         // สีพื้นหลังธีมของการ์ดสายงาน
      iconColor: "...",     
      jobs: [
        {
          id: "ophthalmologist",
          nameT: "จักษุแพทย์ (หมอตา)",
          nameE: "Ophthalmologist",
          icon: "👁",
          img: "...",          
          salary: {
            entry: "100,000",
            mid: "350,000",
            senior: "1,000,000+"
          },
          salaryBar: {          // สัดส่วนความยาวแท่งกราฟ (0-100)
            entry: 30,
            mid: 60,
            senior: 100
          },
          education: "...",     // เส้นทางการศึกษา
          degree: "...",        // วุฒิการศึกษาที่ได้รับ
          years: "...",         // จำนวนปีที่ต้องใช้เรียน
          skills: [...],        // รายการทักษะจำเป็น (Hard/Soft Skills)
          description: "...",   // ข้อมูลภาพรวมหน้าที่การทำงาน
          pros: [...],          // จุดเด่น/ข้อดี
          cons: [...],          // ข้อจำกัด/อุปสรรค
          growth: "...",        // อัตราและแนวโน้มการเติบโตในอนาคต
          tags: [...]           // คำค้นหาที่เกี่ยวข้อง
        }
      ]
    }
  ]
}

```
